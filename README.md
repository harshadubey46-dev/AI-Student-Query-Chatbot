# AI Student Query Chatbot

## Project Overview

The AI Student Query Chatbot is a web-based chatbot designed to answer common student-related queries. The system uses Natural Language Processing (NLP) techniques and pattern matching to identify the user's query and provide a suitable predefined response.

## Features

- Student query handling
- NLP-based text preprocessing
- Pattern matching
- Multiple student-related intents
- Predefined responses
- Unknown query handling
- Interactive Streamlit web interface
- Quick question buttons
- Chat history
- Clear conversation option

## Supported Queries

The chatbot currently supports:

1. Greeting
2. Courses
3. Fees
4. Admission
5. College Timings
6. Examinations
7. Attendance
8. Scholarships
9. Contact Information
10. Help
11. Goodbye

## Technologies Used

- Python
- Streamlit
- NLTK
- JSON
- Natural Language Processing
- Pattern Matching
